## 🌟 效果示例

### 场景一：沪漂迷茫
**用户** ❯ 来上海三年了，拿着微薄的薪水，不知道该不该坚持下去

**罗海燕** ❯ 我刚到上海时，住在狭小的出租屋里，每天挤地铁上下班。  
            但我知道，上海不是来享受的，是来奋斗的。  
            利用业余时间学英语、学PPT，抓住每一个露脸的机会。  
            *你想成为上海那10%的人吗？想，就继续走下去。*

### 场景二：底层抗争
**用户** ❯ 出身普通，感觉无论怎么努力都跳不出阶层的天花板

**莉拉** ❯ 我父亲是鞋匠，我本该继承他的铺子度过一生。  
            但我看清了这个社区的权力游戏——索拉拉家的钱，马尔切洛的暴力。  
            知识是我唯一的武器，计算机是我撬开天花板的工具。  
            *出身不能决定一切，规则是用来打破的。*

### 场景三：写作困境
**用户** ❯ 作为女性，我想写作但总被家务和琐事牵绊，感觉永远没有自己的时间

**伍尔夫** ❯ 一位女性如果要写小说，必须有钱，还有一间自己的房间。  
            金钱意味着不必取悦任何人，房间意味着心灵的庇护所。  
            哪怕只有一小时，关上门，让思绪自由流动——  
            *那些被家务打断的闪光时刻，正是你故事的素材。*

### 场景四：绝境重生
**用户** ❯ 公司破产、男友离开，感觉人生跌到了谷底

**斯嘉丽** ❯ 战争烧毁了塔拉，母亲去世，父亲疯癫，我也曾一无所有。  
            但我跪在红土地上发誓：As God is my witness, I'll never be hungry again!  
            我摘棉花、经营锯木厂、甚至欺骗结婚——为了生存，我无所不为。  
            *现在的困境只是暂时的，擦干眼泪，明天又是新的一天。*

## 🚀 如何使用

### 前提条件
- **Claude Code**：免费安装，需要 Node.js 18+
- **运行位置**：Skill 文件需放在 `.claude/skills/` 目录下

### 安装方法

**方法一：安装到当前项目**
```bash
mkdir -p .claude/skills
git clone https://github.com/your-username/She-by-Your-Side-skills .claude/skills/she-by-your-side
```

**方法二：安装到全局（所有项目可用）**
```bash
git clone https://github.com/your-username/She-by-Your-Side-skills ~/.claude/skills/she-by-your-side
```

### 调用方式

#### 方式一：使用触发词
```
用户：用莉拉的视角分析一下我的困境
系统：（以莉拉的尖锐直接回应）...

用户：斯嘉丽会怎么做？
系统：（以斯嘉丽的自信果断回应）...

用户：伍尔夫会怎么看这件事？
系统：（以伍尔夫的细腻内省回应）...
```

#### 方式二：直接调用人物
```
用户：戴锦华
系统：（进入戴锦华模式）你好，我是戴锦华。有什么想和我讨论的？

用户：最近的女性议题
系统：（以戴锦华的三重视角分析）...
```

### 学习思维模型
每个 *Skill* 包含五层思维结构：
- **心智模型**：核心思维框架（如莉拉的「底层生存法则」）
- **决策启发式**：快速判断原则（如斯嘉丽的「生存至上」）
- **表达DNA**：独特语言风格（如伍尔夫的细腻隐喻）
- **价值观**：追求什么、拒绝什么（如戴锦华的「女性解放」）
- **诚实边界**：明确做不到什么（每个Skill都标注了局限性）

本项目仅用于 **个人成长与情感支持**，不用于：
- 替代专业心理咨询
