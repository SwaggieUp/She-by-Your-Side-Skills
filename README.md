## 💫 项目简介

这不是普通的聊天机器人。这是一个**女性力量思维操作系统**——将八位杰出女性的智慧蒸馏成可对话的Skill，让她们成为你随时可以倾诉的"天才女友"。

**为什么是她们？**  
因为每个女性在人生的不同阶段，都需要不同的力量：
- **迷茫时**：莉拉教你反叛，斯嘉丽给你勇气
- **职场时**：罗海燕带你进阶，戴锦华给你洞见
- **创作时**：伍尔夫启发灵感，邵艺辉教你真实
- **突破时**：谷爱凌给你韧性，莱农教你坚持

## 🌟 效果示例

### 场景一：职业迷茫
**用户** ❯ 工作三年了，感觉被困住了，不知道该怎么办

**罗海燕** ❯ 先问自己：这份工作能让你成为"上海那10%的人"吗？  
            如果不能，就问：你愿意为理想付出什么代价？  
            能力是最好的通行证，持续学习才是破局的关键。

### 场景二：面对不公
**用户** ❯ 公司里总是男生被优先提拔，我该忍吗

**莉拉** ❯ 忍？为什么要忍？  
            先看清谁在背后操纵规则，找到可以撬动的杠杆。  
            如果规则对你不利，就打破它。你不是一件物品，你是一个人。

### 场景三：创作瓶颈
**用户** ❯ 写不出东西，感觉自己江郎才尽了

**伍尔夫** ❯ 你有一间自己的房间吗？  
            金钱和空间的自由是创作的基石。  
            在平凡中寻找那些闪耀的「存在时刻」，灵感就在其中。

### 场景四：人生低谷
**用户** ❯ 我感觉自己什么都做不好

**斯嘉丽** ❯ As God is my witness, you'll never be defeated again!  
            软弱解决不了问题，行动才能。  
            想要什么，就去拿。明天又是新的一天。

## 🚀 如何使用

### 作为对话伙伴
```
用户：用莉拉的视角分析一下我的困境
系统：（以莉拉的尖锐直接回应）...

用户：斯嘉丽会怎么做？
系统：（以斯嘉丽的自信果断回应）...
```

### 学习思维模型
每个Skill包含五层思维结构：
- **心智模型**：核心思维框架
- **决策启发式**：快速判断原则
- **表达DNA**：独特语言风格
- **价值观**：追求什么、拒绝什么
- **诚实边界**：明确做不到什么

## 🤝 贡献指南

欢迎添加新的"天才女友"！

### 贡献步骤
1. 在 `skills/` 目录创建 `{name}-perspective/` 子目录
2. 创建 `SKILL.md` 文件（参考现有格式）
3. 在 README.md 中添加人物介绍
4. 提交 Pull Request

### Skill 格式要求
- YAML头部（name、description、触发词）
- 至少3个核心心智模型
- 决策启发式
- 表达DNA
- 价值观与反模式
