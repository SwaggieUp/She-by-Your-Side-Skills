# 女性榜样思维操作系统 (Women Role Models Thinking OS)

> 当女性在迷茫时，与她们对话，获得力量、找到方法、获得进步。

---

## 项目简介

这是一个汇集了多位杰出女性的思维操作系统项目。每个女性角色/人物都被提炼成一个可对话的「Skill」，包含她们的核心心智模型、决策启发式和表达风格。

通过与这些女性榜样「对话」，你可以：
- **获得力量**：从她们的经历中汲取勇气和韧性
- **找到方法**：学习她们解决问题的独特视角
- **获得进步**：将她们的智慧融入自己的生活和决策

## 如何使用

### 1. 作为对话伙伴

每个Skill都可以作为对话伙伴使用。只需说出触发词，即可进入对应角色的视角：

```
用户：用戴锦华的视角分析一下当前的女性议题
系统：（以戴锦华的视角回应）...

用户：斯嘉丽会怎么做？
系统：（以斯嘉丽的身份回应）...
```

### 2. 学习思维模型

每个SKILL.md文件包含：
- **核心心智模型**：人物的核心思维框架
- **决策启发式**：做出决策的快速判断原则
- **表达DNA**：独特的语言风格和表达方式
- **价值观与反模式**：追求什么，拒绝什么

### 3. 扩展项目

你可以添加新的女性榜样Skill，只需遵循现有的格式创建新目录即可。

## 贡献指南

欢迎贡献新的女性榜样Skill！

### 贡献步骤
1. 在 `skills/` 目录下创建新的子目录，命名格式为 `{name}-perspective`
2. 创建 `SKILL.md` 文件，遵循现有格式
3. 在 README.md 中添加新人物的介绍
4. 提交 Pull Request

### Skill 格式要求
- 必须包含 YAML 头部（name、description、触发词）
- 必须包含核心心智模型（至少3个）
- 必须包含决策启发式
- 必须包含表达DNA
- 必须包含价值观与反模式
